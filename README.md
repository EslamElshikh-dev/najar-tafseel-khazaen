## ما يتضمنه الموقع

- واجهة عربية افتراضيًا مع دعم الإنجليزية والأردية واختيار محفوظ للمستخدم.
- تصميم متجاوب للجوال والكمبيوتر مع أزرار اتصال وواتساب واضحة.
- نموذج طلب يفتح رسالة واتساب مجهزة ببيانات الخدمة.
- بيانات منظمة مترابطة من نوع `LocalBusiness` و`WebSite` و`Person`.
- عنوان ووصف ووسوم Open Graph وTwitter محسنة للمشاركة والبحث.
- خريطة الملف التجاري، وملفا `robots.txt` و`sitemap.xml`.
- تحسينات وصول تشمل عناصر تحكم دلالية، وتسميات للنموذج، ودعم تقليل الحركة.

## بنية المستودع

```text
.
├── .nojekyll
├── CNAME
├── README.md
├── index.html
├── robots.txt
└── sitemap.xml
```

الموقع ثابت ويُنشر من فرع `main` عبر GitHub Pages. يجب إبقاء `CNAME` بالقيمة `njartafsel-khazaen.com`، وعدم إضافة عنوان أو إحداثيات إلا بعد مطابقتها مع بيانات الملف التجاري المعتمدة.

## فحوص ما قبل النشر

1. التأكد من تطابق الاسم والهاتف والنطاق ونطاق الخدمة مع ملف Google.
2. التحقق من صحة JSON-LD وعدم وجود أكثر من عنوان `<title>` واحد.
3. تجربة الاتصال وواتساب ونموذج الطلب على الجوال.
4. تحديث تاريخ `lastmod` في `sitemap.xml` عند أي تعديل جوهري.
5. التأكد من نجاح نشر GitHub Pages بعد الدمج إلى `main`.
